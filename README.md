# PMP Performance Theme

ثيم مستقل لمتجر **PMP Performance** على منصة سلة، بهوية سوداء وحمراء مخصصة لقطع وتعديلات السيارات.

## هوية الثيم

- الاسم: PMP Performance
- المستودع: https://github.com/ABODAH1234/pmp-store-v2
- الموقع: https://pmpperformance.online
- المالك والمطور: PMP Performance
- الإصدار: 1.0.0

هذا المستودع لا يمثل ثيم «رائد» ولا يحمل اسمه أو هويته. يستخدم محرك **Salla Twilight** ومكوناته الرسمية فقط لأنها بيئة التشغيل المطلوبة للثيمات على سلة.

## التشغيل

```bash
pnpm install
pnpm production
```

ملف تعريف الثيم هو `twilight.json`، وملفات الواجهة داخل `src`، والملفات الجاهزة داخل `public`.
